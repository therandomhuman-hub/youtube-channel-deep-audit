# Autonomous hardening iteration 4

Date: 2026-10-06

## Highest-impact weakness
The release builder treated validator exit code 0 as sufficient for release. The validator intentionally returns exit code 0 for WARN, so a package with validation warnings could be labeled RELEASED, violating the clean-release gate.

## Change implemented
- Added release_allowed() to runtime/build_release.py.
- Only validator status PASS can produce release_status=RELEASED.
- WARN and FAIL now block release.
- Added tests/test_release_gate.py covering PASS/WARN/FAIL/missing status.

## Validation
- Code-level regression test added and committed.
- Full GitHub Actions validation must complete on the hardened branch before merge.
