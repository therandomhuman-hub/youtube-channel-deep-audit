# v12.1 Production Hardening — Release Gate Contract

Highest-impact weakness identified: the current validator checks that every video has an audit record, but does not enforce transcript-attempt coverage across the discovered inventory, and its schema does not require the visible audited/guidance layers. This can allow a structurally complete-looking report to pass while silently skipping transcript acquisition or collapsing the evidence layers.

Required invariants:
- transcript_audit.target_video_count equals videos.length.
- transcript_audit.attempted_video_count equals videos.length for a decision-ready release.
- Every video has transcript_audit.status; NOT_ATTEMPTED is not releasable.
- Every video has an individual audit.
- Every video visibly exposes original_evidence, audited_findings (or equivalent), and beginner_guidance/professional guidance.
- Transcript availability never upgrades creator claims to verified truth.
- Missing/unavailable data is never coerced to zero.
- Security and artifact validation remain release blockers.

Compatibility: existing v12 fields remain valid; these are additive release gates. Older reports may remain readable but cannot be decision-ready unless they satisfy the gates.

Implementation target: enforce these invariants in runtime/validate.py and add regression fixtures for skipped transcript attempts and missing report layers.

Status: HARDENING_REQUIRED
