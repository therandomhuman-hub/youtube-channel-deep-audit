# Autonomous hardening iteration 3

Date: 2026-10-06

## Highest-impact weakness
The runtime validator enforced the per-video evidence-layer contract, but the canonical JSON schema was still permissive and did not require the same layers. A producer could therefore pass schema validation with a structurally incomplete per-video object if runtime validation were bypassed or changed.

## Change implemented
- Hardened `schema.json` to v12.1.
- Required per-video `original_evidence`, `audited_findings`, and `beginner_guidance`.
- Constrained per-video decision values to KEEP / TEST / MODIFY / AVOID / RESEARCH MORE.
- Constrained confidence values to LOW / MEDIUM / HIGH.
- Required per-video transcript status and `text_retained=false`.
- Preserved v12.0 compatibility by allowing methodology/schema versions 12.0 and 12.1.
